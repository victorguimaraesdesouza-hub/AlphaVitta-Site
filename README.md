# Alpha Vitta Consultoria — site

Site estático (HTML, CSS e JavaScript, sem framework) da Alpha Vitta Consultoria, consultoria em planos de saúde e odontológicos em São Paulo.

- Abra `index.html` direto no navegador ou publique a pasta em qualquer hospedagem estática.
- Tema claro e escuro, navegação que se adapta à largura da tela, formulário que abre o WhatsApp com a mensagem pronta.
- Fotos: a origem e a licença de cada uma estão no arquivo `.json` ao lado dela, em `assets/fotos/`.
- As marcas das operadoras pertencem aos seus respectivos donos.
